The production identity-mutate census searched the complete scripts tree for identity arrows and inspected `mutateIssueBody` call sites: `defaultProbeCompletion` was the actual read-only identity mutation. Conditional writer no-ops retain their writer classification; they are not observational completion reads. This targeted migration precedes the public writer change.

Recovery guidance is phase dependent. An uncertain or dispatching attempt names the existing `recoverStoryBatch` API with `allowMutation:false`; it observes/reconciles retained evidence and cannot retry a delayed write or complete a transition. A frozen conflict reports manual intervention and no automatic operation. An entirely unattempted prepared journal names the existing `releaseUnattemptedTransition` with its exact batch ID; its actual native fixture retains working bytes, then re-enters a fresh governed transition. A confirmed journal names `runTransitionBatch` with registered owner, exact frozen intent and fresh native guards required; the confirmed fixture resumes without provider replay. Other retained phases without an executable native continuation report manual intervention rather than promising replay. Clean or ordinary dirty work has no repair operation. No cache-recovery CLI verb is invented.

`inventory` remains a compatibility alias for `publishedInventory`, the observed provider comment IDs. `workingCommentKeys` enumerates candidate comment resources, including `comment:new:` keys without fabricated provider IDs. Neither enumeration confers publication.
