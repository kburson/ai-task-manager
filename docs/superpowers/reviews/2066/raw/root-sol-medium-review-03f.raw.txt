**Important — [P1] Preserve fractional GraphQL variables as JSON numbers**

`provider-adapters.mjs:111–115` converts numeric variables into `gh api graphql -F value=...`. Installed `gh api --help` documents conversion of **integer numbers**, not fractional values. Thus a legitimate NUMBER update such as Estimate **3.5** is sent as string `"3.5"` to the `$value:Float!` mutation constructed at lines 181–183. GitHub rejects the mutation; the publisher then consumes its single attempt and can leave the batch uncertain.
