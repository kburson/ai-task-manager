# R4R (Ready For Release) State Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "R4R" (Ready For Release) as a new Kanban state between In Review and Done, with cascade close for epics and a parent-state guard for child issues.

**Architecture:** The new state slot is wired through config (one new key), the move-state script (one new case), init (column setup), and task-tracker.mjs (`verbReview` gains a post-verification R4R promotion step; `verbClose` gains cascade + parent guard). Three new async helpers in task-tracker.mjs query GitHub for sub-issues, parent issue, and board state.

**Tech Stack:** Node.js ESM, Bash, GitHub GraphQL API v4, `gh` CLI, GitHub Projects V2.

---

## New Flow

```
Backlog → Ready → In Progress → In Review → R4R → Done
```

| State | Who moves here | How |
|---|---|---|
| In Review | Agent (CODE_COMPLETE) | `/task review <issue>` — moves here first, then runs verification |
| In Progress | Agent (verification failure) | `/task review` fails → auto-reverts; agent fixes defect and loops |
| R4R | Agent (verification passes) | `/task review` promotes automatically after all boxes pass |
| Done | Human-triggered cascade | `/task close <epicId>` or `/task close <soloId>` |

**`/task review` is a gate, not a one-way door:**
1. Moves issue from In Progress → In Review
2. Checks all unchecked boxes (AC, DoD, Verification Commands)
3. **Fail:** reverts to In Progress — agent fixes defect, loops back to step 1
4. **Pass:** promotes to R4R and pauses the task

**Epic rules:**
- Epic can move to R4R only when all sub-issues are already R4R (checked after box verification).
- `/task close <epicId>` verifies all children are R4R, closes each child (board + GitHub issue), then closes the epic.
- A child issue cannot close if its parent epic is not in R4R or Done.

async function runMoveState(issue, state, { env: envOverride } = {}) {
  if (SKIP_NETWORK) return;
  const scriptPath = new URL('../gh/move-state.sh', import.meta.url).pathname;
  const issueNum = String(issue).replace(/^#/, '');

  return Object.fromEntries([

- [ ] **Step 3: Extend `verbReview` — add R4R promotion after passing verification**

The existing `verbReview` already moves to `in-review`, checks boxes, and reverts to `in-progress` on failure. Keep all of that. Add only the success path: after the unchecked-box check exits without error, run the epic sub-issue gate, then promote to R4R.

The existing function ends at line ~461. Replace the full function with this updated version (the first two branches — active-session and non-active-session — are structurally unchanged; timing event description updates from "starting review" to "starting review / gate to R4R", and two new blocks are added after the unchecked check):

```js
async function verbReview(args) {
  await draiQueueIfAny();
  const s = loadState(statePath);
  const target = args.find(a => /^#\d+$/.test(a)) || (s.active && s.active !== 'plan' ? s.active : null);
  if (!target) {
    console.error('Usage: /task review #N');
    process.exit(1);
  }
  // ── Move to In Review and flush/pause timing ──────────────────────────────
  if (s.active === target) {
    const { deltaMin, deltaWallMin, deltaWords } = await flushActiveToGH(s, 'review', 'starting review');
    const wallNote = deltaWallMin !== deltaMin ? ` (wall ${deltaWallMin})` : '';
    saveState({
      ...s,
      active: null,
      entryStartTs: null,
      wordsAtEntryStart: 0,
      lastActive: target,
    }, statePath);
    try { setTaskStatus(projectDir, target, 'paused'); } catch {}
    await runMoveState(target, 'in-review');
    console.log(`In Review ${target}: +${deltaMin} active min${wallNote}, +${deltaWords} words; verifying...`);
  } else {
    const ts = nowIso();
    const row = (await import('./gh-timing-comment.mjs')).buildRow({
      ts, event: 'review', activeMin: 0, idleMin: 0, deltaWords: 0,
      wordMarker: 0, description: 'starting review',
    });
    await safePostTiming(target, row);
    await runMoveState(target, 'in-review');
    saveState({ ...s, active: null, entryStartTs: null, wordsAtEntryStart: 0, lastActive: target }, statePath);
    console.log(`In Review ${target}: verifying...`);
  }
  if (!SKIP_NETWORK) {
    const issueNum = target.replace(/^#/, '');
    // ── Unchecked-box gate: revert to In Progress on failure ─────────────────
    const { stdout: bodyOut } = await pexec('gh', [
      'issue', 'view', issueNum, '-R', cfg.repo, '--json', 'body',
    ], { timeout: 10000 });
    const body = JSON.parse(bodyOut).body ?? '';
    const unchecked = uncheckedPreCloseCheckboxes(body);
    if (unchecked.length > 0) {
      await runMoveState(target, 'in-progress');
      console.error(`[task-tracker] ⛔ Review failed for ${target} — reverted to In Progress:`);
      unchecked.forEach(u => console.error(`   ${u}`));
      console.error('Fix each item, check its box (`/task check "<label>"`), then run `/task review` again.');
      process.exit(3);
    }
    // ── Epic sub-issue gate: all sub-issues must be R4R ───────────────────────
    const subNums = await fetchSubIssues(issueNum);
    if (subNums.length > 0) {
      const childStates = await Promise.all(
        subNums.map(async n => ({ num: n, state: await getIssueBoardState(n) }))
      );
      const notR4R = childStates.filter(c => c.state !== 'r4r');
      if (notR4R.length > 0) {
        // Stay in In Review — the epic's own boxes pass but children aren't ready
        console.error(`[task-tracker] ⛔ Epic ${target} cannot move to R4R — ${notR4R.length} child issue(s) not in R4R:`);
        notR4R.forEach(c => console.error(`   #${c.num}: ${c.state ?? 'unknown'}`));
        console.error('Wait for all sub-issues to reach R4R, then run `/task review` again.');
        process.exit(3);
      }
    }
    // ── All gates passed: promote to R4R ─────────────────────────────────────
    await runMoveState(target, 'r4r');
    const ts = nowIso();
    const r4rRow = (await import('./gh-timing-comment.mjs')).buildRow({
      ts, event: 'r4r', activeMin: 0, idleMin: 0, deltaWords: 0,
      wordMarker: 0, description: 'verification complete — moved to R4R',
    });
    await safePostTiming(target, r4rRow);
    console.log(`✓ ${target} moved to R4R — all verification passed.`);
  }
}
```

  // ── Cascade close (epic) or parent guard (child) ──────────────────────────
  if (!SKIP_NETWORK) {
    const issueNum = s.active.replace(/^#/, '');
    const subNums = await fetchSubIssues(issueNum);

    if (subNums.length > 0) {
      // Epic: verify all children are R4R (or already Done)

          try {
            await runMoveState(child.num, 'done', { env: { AITM_CASCADE: '1' } });

            console.log(`  ✓ #${child.num} closed`);
          } catch (err) {
            console.warn(`  ⚠ Could not close #${child.num}: ${err.message}`);
          }

        }
