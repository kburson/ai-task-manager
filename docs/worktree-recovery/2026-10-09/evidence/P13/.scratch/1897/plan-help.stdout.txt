/task plan — Ready for Planning→Plan (JIT planning entry); distinct from discover backlog item generation. Refuses on any other current state.

  Purpose: Ready for Planning→Plan (JIT planning entry); distinct from discover backlog item generation. Refuses on any other current state.
  Usage:  /task plan #N

  Arguments:
    #N
        Issue number to move from Refine to Plan.

  Preconditions:
    The numbered issue must exist in Ready for Planning and satisfy the R4P-to-Plan entry gates.

  Effects:
    Moves the issue one edge into Plan without running discovery-plan generation.

  Output:
    Prints gate failures or the confirmed Plan state.

  Exit codes:
    0  success (or idempotent no-op)
    1  runtime error (message on stderr)
    2  usage error / unknown verb
    4  gate refused the transition (blockers printed); state unchanged

  Examples:
    /task plan 667

  Related:
    plan-estimate
    plan-approve
    promote
