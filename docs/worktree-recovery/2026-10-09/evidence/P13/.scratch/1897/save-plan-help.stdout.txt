/task save-plan — Save a discovery plan markdown to docs/plans/ and stamp its path into the active bucket.

  Purpose: Save a discovery plan markdown to docs/plans/ and stamp its path into the active bucket.
  Usage:  /task save-plan --from-file <path> [--title <override>]

  Arguments:
    --from-file <path>
        plan markdown (required)
    --title <override>
        title override

  Preconditions:
    An active discovery bucket and readable --from-file markdown are required.

  Effects:
    Writes the plan under docs/plans and records its path in discovery state.

  Output:
    Prints the saved plan path.

  Exit codes:
    0  success (or idempotent no-op)
    1  no active discover state
    2  usage error / unknown verb

  Examples:
    /task save-plan --from-file .scratch/plan/help-rework.md

  Related:
    save-draft
    new
    cancel
