CLI:
  aitm                     Discover and route AITM workflow verbs and shipped standalone commands.

Diagnostics:
  doctor                   Report read-only bootstrap health for the installed AITM project contract.
  guidance                 Inspect and validate the selected guidance source without operational effects.

Epic Branching:
  cut-child-worktree       Correct-by-construction child worktree: `git worktree add -b feature/child/<N> <path> <epicHead>`. The owned replacement for native worktree isolation on epic children.
  cut-epic-branch          Cut a role-typed epic branch `feature/epic/<N>` from its resolved parent head (trunk for a root epic, the outer epic for a nested one).
  draft-branch             Create the canonical issue draft branch in a clean detached linked worktree, then renew exact binding.
  merge-back               Merge a child back into its epic: opportunistic epic sync, rebase child onto epic head, verify through the configured project provider or Node defaults, then `--ff-only` the verified commit. Refuses conflicts, failed verification, or checkout drift.
  sync-epic                Re-sync an epic branch onto trunk (rebase, then push --force-with-lease unless noPushToOrigin). Keeps the epic a clean linear descendant of trunk.

GitHub:
  capture-actions          Control and inspect temporary, local capture of GitHub-bound task actions.
  create-issue             Atomically create a GitHub issue: gh create + project tether + sub-issue link.
  log-issue-time           Roll up an issue ⏱ Timing Log into the board Engaged/Session/Review/Plan fields.
  preflight-issue          Stamp the DoD + Pickup-Directive tail onto a draft issue body before creation.
  project-tether           Attach an issue to the configured GitHub Project and return its project item id.
  set-priority             Set the Priority field on an issue (optionally cascading to sub-issues).
  set-rank                 Set the Rank (wave-order) number field on an existing issue's project item.
  update-event-fields      Repair the per-stage event timestamp fields (Start/Plan/Develop/...) on the board.

Maintenance:
  heal-backlog             Normalize body encodings, reconcile aitm-fields vs the timing log, validate field schema. `--rename-timing-slugs` rewrites historical timing-log Event slugs to the #516 vocabulary.

Package lifecycle:
  ai-task-manager          Install, uninstall, initialize, repair, configure, and inspect the AITM package.

Parallel:
  dispatch-prep            Claim a sub-issue for an agent: flip the board to In Progress and post a start timing row.
  ensure-wave-parent       Pre-flight a fan-out: create/reuse a shared wave-parent issue and re-parent solo children.

Reports:
  measure-context          Measure context-word usage for a session/issue.
  value-report             Generate the AI-value / project report from the GitHub Project board.

Workflow:
  verify-delivery-incident-reconciliation Read-only verification of the approved #1381 incident ledger and outcomes.
  verify-develop           Run affected Develop iteration checks or clean exact-SHA finalization.
