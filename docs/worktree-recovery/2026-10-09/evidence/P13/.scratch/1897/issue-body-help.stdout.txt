/task issue-body — Apply one governed, declarative fresh-base issue-body operation from a JSON file.

  Purpose: Apply one governed, declarative fresh-base issue-body operation from a JSON file.
  Usage:  /task issue-body #N --operation-file <path>

  Arguments:
    #N
        Issue number whose fresh body will be transformed.
    --operation-file <path>
        aitm.issue-body-operation/v1 exact or named-section replacement

  Preconditions:
    The target must be the active issue with an open timing session, matching assignee, matching worktree, and a valid aitm.issue-body-operation/v1 file.

  Effects:
    Evaluates one exact or named-section replacement against every fresh remote body through mutateIssueBody and verifies the persisted body.

  Output:
    Prints the mutation status and verified body version.

  Exit codes:
    0  success (or idempotent no-op)
    1  runtime error (message on stderr)
    2  usage error / unknown verb
    7  target differs from the active issue binding
    9  live board state differs from the recorded state marker
    10  issue assignee is mismatched, absent, or unverifiable

  Examples:
    /task issue-body 667 --operation-file .scratch/gh/667-body-operation.json

  Related:
    comment
    evidence-markers
