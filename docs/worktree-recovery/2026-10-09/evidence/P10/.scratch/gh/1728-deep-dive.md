## Deep-Dive Analysis (2026-09-21)

The pinned Task 1 boundary is an observation collector, not an action evaluator. The existing `action-decision/contract.mjs` already closes authority resource and producer IDs and defines `authority-read-failed` and `authority-read-skipped`; the new collector must use these rather than invent readiness codes. `workflow-policy/snapshot.mjs` is a useful read-only precedent but its runtime ports are broader than the minimal collector and it hashes only a subset of read data. `move-state/guard-execution.mjs`, `guard-registry.mjs`, and `verbs/promote.mjs` remain untouched in this child. They are Task 2's consumers and mutation migration.

Files to edit: create `scripts/task-tracker/lib/action-decision/observations.mjs` and `scripts/tests/unit/task-tracker/lib/action-observations.test.mjs`. Add a workflow-policy read-only seam only if the collector cannot use its caller-supplied read port without changing the existing preflight behavior. No new public command, registry adapter, or general-purpose write-capable port is in scope.

Implementation sequence: (1) write focused tests for attempt-local reuse and incompatible identity, source, and body; (2) run them RED against the missing export; (3) add a minimal `createObservationAttempt` API requiring repository, issue, boundary, scope, and a caller-supplied read-only source port; (4) record each source's observation time, canonical content digest and normalization inputs in an immutable result and derive the attempt window from those times; (5) convert missing, malformed, incompatible, and failed reads into typed indeterminate collection causes with original error provenance, never a ready/default value; (6) enforce one-attempt memoization keyed by complete identity and disallow effectful read operations; (7) run focused tests GREEN, run repository-required checks, and document the exact handoff to Task 2. Any refresh after a changed body, repository, issue, scope, retry, or effect creates a fresh attempt; the collector does not authorize a mutation.

Tests: `scripts/tests/unit/task-tracker/lib/action-observations.test.mjs` exercises complete identity and attempt isolation, single-read memoization, immutable provenance and digest, distinct observation times, required read failure, missing source, incompatible repository/issue/body, and attempted local/Git/network effects. A harness-owned effect ledger records each attempted forbidden operation before a fake transport may throw; assertions inspect that ledger in `finally` independent of collector status, including a forbidden `fetch` attempt. A thrown test hook is separate from an actual effect attempt.

Risks: a digest that omits normalization inputs can make semantically distinct observations look equal; a shared cache can reuse stale authority across commands; shallow freezes can permit a consumer to mutate nested evidence; treating a skipped or failed source as empty authority can falsely indicate readiness. Task 2 must preserve the complete guard arrays, warnings, human requests, and known refusals when it consumes this collector; this child cannot claim those semantics on its own.
