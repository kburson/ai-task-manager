A mismatched preference is not a failed predicate; a wrong PR or accepted head remains one.

For a two-parent merge, require the PR merge commit's second parent to equal the accepted head, and prove resulting content relative to the first parent. A merge commit tree may differ from the accepted head tree if the base moved, so literal head-tree equality is only one special case. For a squash, require a one-parent result and a complete source inventory whose source delta maps to the integrated result. For a rebase, source commits are rewritten; require a complete ordered source-to-replay mapping and content equivalence rather than SHA equality. A single-parent shape or a familiar title cannot by itself distinguish squash from rebase. Where topology or content mapping is ambiguous, return a typed refusal. In all methods the merged SHA must be reachable from the freshly fetched origin/trunk, and contradictory source attribution must fail even if content appears equivalent.
