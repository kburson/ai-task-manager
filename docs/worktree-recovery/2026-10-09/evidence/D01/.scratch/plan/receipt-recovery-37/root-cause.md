The delivery verifier treats canonical commit-message attribution bytes as mandatory authority even when stronger independent evidence already establishes the exact delivery. For a single-source squash merged before `deliver` creates an intent, a leading issue token is insufficient and a missing terminal trailer has no sanctioned post-merge reconciliation path. The only available way to change immutable merge bytes is to manufacture another branch/PR/merge cycle.

This conflates a useful audit convention with a safety-critical identity boundary. It also emits category-only failures that do not distinguish an unattributed source commit from a valid merge missing one recoverable trailer. The recovery loop then exercises timing transitions that can append a redundant same-second reengagement, while the timing healer supports insertion or removal of a previously fabricated pair but not safe deletion of the exact standalone zero-duration row.
