Codex worktrees with AITM's Codex Superpowers bootstrap instruct agents to load mirrored Superpowers from ~/.codex/skills. The packaged Bash PreToolUse guard currently permits reads from the project root, ~/.claude/, and system paths, but blocks ~/.codex/skills. As a result, the first required skill load in a Codex workspace can be refused by AITM's own hook. The package should allow read-only access to ~/.codex/skills while retaining existing write restrictions and other path-scope protections.
