All 36 current basenames, hence generated session IDs, are distinct. This lets existing real `saveState`/marker operations establish their own actor instead of relying on an absent or inherited session. It does not disable production actor validation.
2. **Process scope.** `scripts/run-tests.mjs:166–175` runs each test file in a separate child process. The helper's process-global environment assignment therefore does not spill into later files through the repository runner. Subprocess-based cross-close coverage inherits the fixture identity and still asserts the specific issue-binding mismatch and exit code.
3. **Identity fallback tests remain meaningful.** The word-counter test explicitly sets its Codex provider and clears explicit, Claude, and Codex identity variables before testing transcript fallback and the default-session sentinel. It restores the saved fixture identity afterward. Adding the helper does not cause those fallback assertions to resolve via its explicit identity.
4. **State-sensitive tests still reach real actor state.** State, binding-survives-Test, Review timing, Update, and checklist tests use `saveState` to seed actor-owned state. Read-back, elapsed/word-marker, body-mutation, side-effect, and refusal assertions remain in place. The focused run exercises positive behavior as well as refusal/no-op cases.
5. **Legacy shared-state fixtures.** Some existing coverage/Close repair fixtures still write compatibility JSON directly; that does not create an actor binding. I checked their relevant assertions and explicit target/dependency injection rather than assuming the JSON supplied effective actor state. For example, Close repair verifies terminal effects and the injected timing replay with an explicit target; coverage Review verifies actual move, log-time and review-pass row effects. These tests should not be cited as general proof that legacy shared active state is authoritative. This limitation predates the helper and is not a cleanup regression.
6. **Scope and safety.** No production files changed. The helper does not make tests hermetic against every possible inherited environment variable; the reviewed claim is ownership of actor identity. Existing test fixtures still own project roots and subprocess doubles.
